1. บทนำและที่มาของโครงการ (Problem & Motivation)

ในระบบสารสนเทศของสถาบันการศึกษาหรือองค์กรยุคใหม่ มักประกอบไปด้วยเว็บแอปพลิเคชันที่หลากหลาย เช่น ระบบจองห้องปฏิบัติการคอมพิวเตอร์ ระบบยืม-คืนอุปกรณ์ และระบบสารสนเทศวิชาการ หากออกแบบระบบในรูปแบบดั้งเดิม (Traditional Isolated Architecture) แต่ละเว็บแอปพลิเคชันจะต้องรับผิดชอบการเชื่อมต่อเพื่อยืนยันตัวตนไปยังเซิร์ฟเวอร์หลัก (เช่น RADIUS Server) ด้วยตนเอง ซึ่งก่อให้เกิดปัญหาสำคัญ 3 ประการ:

1. ประสบการณ์ใช้งานแย่

ผู้ใช้งานต้องจดจำและกรอกชื่อผู้ใช้/รหัสผ่านซ้ำๆ ทุกครั้งเมื่อเปลี่ยนไปใช้งานแอปพลิเคชันอื่นภายในเครือข่าย

2. ความเสี่ยงด้านความปลอดภัย

รหัสผ่านวิ่งผ่านเว็บแอปพลิเคชันหลายตัว เสี่ยงต่อการถูกดักจับหรือเกิดจุดรั่วไหลจากแอปพลิเคชันที่ไม่ได้มาตรฐาน

3. ภาระเซิร์ฟเวอร์มหาศาล

RADIUS Server ต้องรับภาระการตรวจสอบรหัสผ่านซ้ำซ้อนอย่างต่อเนื่องในทุกๆ หน้าเว็บที่มีการร้องขอ

แนวทางการแก้ไข: โครงการนี้ได้ประยุกต์ใช้แนวคิด Central Authentication Service (CAS) และ Single Sign-On (SSO) เพื่อสร้างจุดยืนยันตัวตนส่วนกลาง (Identity Provider - IdP) ทำหน้าที่ติดต่อกับ FreeRADIUS เพียงจุดเดียว โดยแยกกระบวนการยืนยันตัวตน (Authentication) ออกจากการควบคุมสิทธิ์และการทำงานของแอปพลิเคชันปลายทาง (Authorization & Business Logic) อย่างเด็ดขาด

4. ขั้นตอนการทำงานของระบบ Single Sign-On (SSO Workflow)

ขั้นตอนที่ 1: ตรวจสอบสิทธิ์ที่แอปปลายทาง (Intercept & Redirect)

เมื่อผู้ใช้เปิดเข้า http://localhost/lab/ ตัว Web App 1 Middleware จะอ่านคุกกี้ชื่อ sso_token หากไม่พบ จะทำการ Redirect เบราว์เซอร์ไปยังหน้า Login กลางอัตโนมัติ: http://localhost/auth/login?redirect_url=/lab/

ขั้นตอนที่ 2: ยืนยันตัวตนกับ FreeRADIUS (UDP Access-Request)

ผู้ใช้กรอก Username และ Password ที่หน้า Central Auth ตัวเซิร์ฟเวอร์จะเข้ารหัสแพ็กเก็ต RADIUS และยิงผ่าน UDP พอร์ต 1812 ไปยัง FreeRADIUS Server โดยมีกลไก Timeout 3 วินาทีเพื่อป้องกันระบบค้าง

ขั้นตอนที่ 3: ตอบรับและสร้างบัตรผ่าน (Issue Signed JWT)

เมื่อ FreeRADIUS ตอบกลับเป็น Access-Accept ตัว Central Auth จะบันทึก Audit Log ลง PostgreSQL แล้วสร้าง JSON Web Token (JWT) โดยมี Payload บรรจุข้อมูลผู้ใช้ (studentId, username, role) พร้อมลงลายมือชื่อดิจิทัลด้วย JWT_SECRET

ขั้นตอนที่ 4: เก็บรักษาใน HTTPOnly Cookie และ Redirect กลับ

Central Auth ส่ง Token กลับไปในรูปแบบ HTTPOnly Cookie พร้อมตั้งค่า Path: / และ Max-Age: 2 ชั่วโมง จากนั้น Redirect ผู้ใช้กลับไปยัง redirect_url ที่ส่งมาตั้งแต่แรก

ขั้นตอนที่ 5: ตรวจสอบสิทธิ์แบบ Stateless (เข้าใช้งานได้ทันที)

Web App 1 ได้รับ Token ผ่าน Cookie และทำการ Verify Signature ด้วยกุญแจลับร่วมกัน (Shared Secret) หากถูกต้อง จะอนุญาตให้เข้าใช้งานระบบทันที โดยไม่ต้องติดต่อไปยัง FreeRADIUS ซ้ำอีก

ขั้นตอนที่ 6: การทำงานของ SSO ข้ามระบบ (Seamless Cross-App Access)

เมื่อผู้ใช้คลิกสลับไป http://localhost/equipment/ (Web App 2 บนพอร์ต 4002) เบราว์เซอร์จะแนบคุกกี้ตัวเดิมไปด้วย Web App 2 จึงสามารถตรวจสอบและอนุญาตให้ใช้งานได้ทันที โดยผู้ใช้ไม่ต้องล็อกอินใหม่แม้แต่ครั้งเดียว

5. เจาะลึกการพัฒนาโค้ดและจุดเด่นทางเทคนิค (Code Deep Dive)

5.1 กลไกป้องกัน UDP Hang ด้วย Timeout 3 วินาที (Central Auth)

โปรโตคอล UDP ไม่มีกระบวนการ Handshake และไม่มีการแจ้งเตือนเมื่อเซิร์ฟเวอร์ปลายทางดับ หากไม่จัดการ Timeout ตัว Node.js Event Loop จะเปิด Socket ค้างไว้จนสูญเสียทรัพยากร ระบบจึงกำหนด Timeout ไว้อย่างรัดกุม:

// central-auth/server.js
function authenticateRadius(username, password) {
  return new Promise((resolve, reject) => {
    const client = dgram.createSocket('udp4');
    let responded = false;

    // เข้ารหัส RADIUS Access-Request (RFC 2865)
    const packet = radius.encode({
      code: 'Access-Request',
      secret: RADIUS_SECRET,
      attributes: [['User-Name', username], ['User-Password', password]]
    });

    // ป้องกัน UDP Hang ด้วย Timeout 3 วินาที
    const timeout = setTimeout(() => {
      if (!responded) {
        responded = true;
        try { client.close(); } catch (e) {}
        reject(new Error('RADIUS Server connection timed out (3s). FreeRADIUS might be offline.'));
      }
    }, 3000);

    client.on('message', (msg) => {
      if (responded) return;
      responded = true;
      clearTimeout(timeout);
      client.close();
      const response = radius.decode({ packet: msg, secret: RADIUS_SECRET });
      if (response.code === 'Access-Accept') resolve(true);
      else resolve(false);
    });

    client.send(packet, 0, packet.length, 1812, RADIUS_HOST);
  });
}

5.2 การตรวจสอบบัตรผ่านแบบ Stateless ในแอปปลายทาง

ใน Web App 1 และ Web App 2 ใช้ Middleware สกัด Cookie และถอดรหัสลายเซ็นโดยตรง ทำให้ระบบมีความเร็วสูงและไม่เกิดคอขวดที่เซิร์ฟเวอร์กลาง:

// web-app-1/app.js & web-app-2/app.js
function requireAuth(req, res, next) {
  const token = req.cookies['sso_token'];
  if (!token) {
    const redirectUrl = encodeURIComponent(req.originalUrl || '/');
    return res.redirect(`${AUTH_URL}/login?redirect_url=${redirectUrl}`);
  }

  jwt.verify(token, JWT_SECRET, (err, decoded) => {
    if (err) {
      // โทเคนหมดอายุหรือลายเซ็นไม่ถูกต้อง
      const redirectUrl = encodeURIComponent(req.originalUrl || '/');
      return res.redirect(`${AUTH_URL}/login?redirect_url=${redirectUrl}`);
    }
    req.user = decoded; // ส่งข้อมูลผู้ใช้ (studentId, username) ไปยัง Route Handler
    next();
  });
}

5.3 การจัดการความปลอดภัยระดับสูง (Security Hardening)

🛡️ การรับมือ BlastRADIUS (CVE-2024-3596)

ช่องโหว่ระดับสากลในโปรโตคอล MD5 ของ RADIUS ที่ประกาศในปี 2024 ทำให้ FreeRADIUS เวอร์ชันใหม่เข้มงวดเป็นพิเศษ ในระบบนี้ได้ปรับแต่งคอนฟิก clients.conf และสิทธิ์ Subnet ให้ถูกต้อง เพื่อให้ Central Auth สามารถเชื่อมต่อได้อย่างปลอดภัยและเสถียร

🔒 Linux File Permission บน Docker

FreeRADIUS มีกลไกป้องกันไฟล์คอนฟิกไม่ให้ Globally Writable เพื่อป้องกันการแก้ไขโดยมิชอบ โครงการนี้ได้เขียน Dockerfile ให้ตั้งค่า chmod 640 และกำหนดเจ้าของไฟล์เป็น root:freerad ตามมาตรฐานความปลอดภัยระดับ Production

8. สรุปผลประโยชน์ที่ได้รับ (Conclusion & Benefits)

  • ความปลอดภัยสูงสุด (Enhanced Security): รหัสผ่านจริงถูกเก็บไว้ที่ FreeRADIUS เพียงแห่งเดียว และถูกส่งผ่านเฉพาะช่องทาง Central Auth เท่านั้น โดยคุกกี้ JWT ป้องกันการขโมยด้วย HTTPOnly
  • ลดภาระโครงสร้างพื้นฐาน (High Scalability): แอปพลิเคชันปลายทางตรวจสิทธิ์แบบ Stateless ในระดับหน่วยความจำ ไม่ต้องทำ I/O หรือคิวรี RADIUS ซ้ำซ้อน
  • ประสบการณ์ผู้ใช้งานที่ไร้รอยต่อ (Seamless UX): ล็อกอินเพียงครั้งเดียวสามารถเข้าถึงทุกบริการของสถาบันการศึกษาได้อย่างสะดวกรวดเร็ว
